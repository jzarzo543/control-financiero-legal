Política de privacidad

1. Responsable y contacto

El responsable de esta aplicación de uso estrictamente personal es el titular de Control Financiero Personal. Para consultas sobre privacidad o el ejercicio de derechos, puede escribir a jzarzo@gmail.com.

2. Qué hace actualmente la aplicación

Control Financiero Personal es una aplicación privada de uso personal para consultar y organizar información financiera que introduce su titular, como apuntes, importes, fechas, conceptos y deudas. Los datos de trabajo se guardan en un servidor privado y el acceso se realiza mediante una conexión HTTPS privada.

Actualmente no hay una conexión de Open Banking con ING ni se importan automáticamente sus cuentas o movimientos. La aplicación no ofrece transferencias, pagos ni órdenes bancarias.

3. Conexión bancaria prevista, todavía inactiva

En el futuro se prevé solicitar, con autorización expresa del titular, acceso de solo lectura a cuentas propias de ING España. La finalidad sería consultar saldos y movimientos y, cuando la entidad lo facilite, los intereses. Se estudia utilizar Enable Banking como proveedor de acceso a información de cuentas.

Esta integración no está implementada ni conectada. Si se activa, se solicitarán únicamente permisos de consulta de información de cuentas; la aplicación no iniciará pagos ni transferencias. Antes de activarla se actualizará esta política para describir el flujo de datos, la conservación y el mecanismo para revocar el consentimiento.

4. Datos y finalidades

  • Funcionamiento actual: información financiera que el titular introduce para mostrar y administrar su situación en la aplicación.
  • Si se implementa Open Banking: datos de cuenta, saldos, movimientos, fechas, descripciones e intereses que ING/Enable Banking permitan consultar, únicamente para mostrarlos al titular y evitar importaciones duplicadas.
  • Seguridad y operación: datos técnicos que puedan tratar los proveedores de alojamiento y de acceso para prestar y proteger sus servicios, conforme a sus propias políticas.

No se usan estos datos para publicidad, perfiles comerciales, venta de información ni para prestar servicios a terceros.

5. Dónde se guardan y quién puede recibirlos

La información de la aplicación se mantiene en el servidor privado del titular. Actualmente no se ha activado ningún proveedor bancario para esta aplicación. Si se habilita la consulta bancaria, ING y el proveedor de acceso Open Banking tratarán los datos necesarios para prestar el servicio autorizado; se informará de su papel y del flujo concreto antes de activar la función.

Si estas páginas se publican en GitHub Pages, GitHub prestará el alojamiento de documentos visibles públicamente y podrá tratar y registrar datos técnicos de visitantes, incluidas direcciones IP, por motivos de seguridad y operación, conforme a sus propias condiciones y política de privacidad. Allí se publicarán únicamente estas páginas informativas, nunca la aplicación ni sus API.

6. Conservación y copias de seguridad

Los datos introducidos se conservan en la aplicación hasta que el titular los elimina. Se realizan copias automáticas y se conservan las 30 más recientes. Estas copias actualmente no están cifradas.

Eliminar un dato de la aplicación no lo elimina inmediatamente de las copias ya creadas; dejará de estar incluido cuando esas copias salgan de la retención. Si se omiten ejecuciones de copia, el tiempo transcurrido hasta su eliminación puede superar 30 días. La integración bancaria no está activa; antes de activarla se informará de la conservación y el borrado de cualquier dato bancario consultado.

7. Seguridad y acceso

El acceso a la aplicación está limitado al titular mediante autenticación y una conexión HTTPS privada. Las copias de seguridad no están cifradas. Estas medidas reducen algunos riesgos, pero ningún sistema puede garantizar seguridad absoluta. El titular debe proteger sus dispositivos y sus credenciales de acceso.

8. Derechos y consultas

Para solicitar acceso, rectificación, supresión u otra consulta sobre datos personales, puede escribirse a jzarzo@gmail.com. También podrán ejercerse los derechos que correspondan ante la autoridad de protección de datos competente.

9. Cambios

Esta política se actualizará antes de activar nuevas fuentes de datos o cambiar las finalidades. La versión vigente indicará su fecha de revisión.
